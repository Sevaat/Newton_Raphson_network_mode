# Newton-Raphson Network Mode

> Расчёт установившегося режима электрической сети методом Ньютона-Рафсона

Веб-приложение для анализа установившихся режимов электроэнергетических систем с использованием итерационного метода Ньютона-Рафсона. Проект включает вычислительное ядро на Python, REST API на Django и интерактивный веб-интерфейс на React.

## Описание

Проект реализует численный метод Ньютона-Рафсона для решения системы нелинейных уравнений установившегося режима электрической сети. Поддерживаются:

- **Узлы различных типов**: нагрузочные (PQ), генераторные (PV), балансирующие (slack)
- **Ветки сети**: линии электропередачи, двухобмоточные и трёхобмоточные трансформаторы
- **Матрица проводимостей**: автоматическое формирование узловой матрицы проводимостей (Y-bus)
- **Итерационное решение**: метод Ньютона-Рафсона с формированием якобиана и проверкой сходимости
- **Постобработка**: расчёт мощностей балансирующего узла и потокораспределения по ветвям
- **Веб-интерфейс**: интерактивная визуализация и управление расчётами через браузер

## Установка и запуск

### Предварительные требования

- Python ≥ 3.14
- Node.js ≥ 18
- [Poetry](https://python-poetry.org/docs/#installation)

### Backend

```bash

git clone https://github.com/Sevaat/Newton_Raphson_network_mode.git
cd Newton_Raphson_network_mode

# Установить зависимости Python
poetry install

# Активировать виртуальное окружение
poetry shell

# Запустить миграции Django
cd backend
python manage.py migrate

# Запустить сервер разработки
python manage.py runserver
```

### Frontend

```bash

cd frontend

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Сборка для продакшена
npm run build
```

### Консольный запуск (без веб-интерфейса)

```bash
# Запуск расчёта из командной строки
python main.py
```

## Использование

### Консольный режим

Основной скрипт `main.py` выполняет полный цикл расчёта:

```python
from src.nr_method import NewtonRaphsonMethod
from src.postprocessing import calc_results
from src.util.file_manager import FileManager

def main(filepath: str):
    # 1. Загрузка данных из JSON-файла
    loads, nodes, branches, parameters = FileManager.load(filepath)

    # 2. Расчёт установившегося режима методом Ньютона-Рафсона
    nodes, branches, parameters = NewtonRaphsonMethod.run(nodes, branches, parameters)

    # 3. Постобработка: мощности балансирующего узла и потоки по ветвям
    slack_powers, flows = calc_results(nodes, branches)

    # 4. Сохранение результатов
    FileManager.save(loads, nodes, branches, parameters, slack_powers, flows)
```

### Этапы расчёта

1. **Загрузка данных** — чтение параметров сети из JSON-файла (узлы, ветви, нагрузки)
2. **Формирование матрицы проводимостей** — построение узловой матрицы Y-bus
3. **Итерационный процесс** — решение системы нелинейных уравнений методом Ньютона-Рафсона
4. **Проверка сходимости** — контроль невязок по_active_ и _reactive_ мощностям
5. **Постобработка** — вычисление мощностей в балансирующем узле и потокораспределения

## Формат входных данных

Входные данные представляются в формате JSON и содержат:

- **Узлы** (`nodes`) — список узлов электрической сети с указанием типа (PQ, PV, slack), напряжения, генерации и нагрузки
- **Ветви** (`branches`) — список ветвей (линий и трансформаторов) с параметрами сопротивлений и проводимостей
- **Нагрузки** (`loads`) — данные о нагрузках в узлах сети
- **Параметры** (`parameters`) — настройки итерационного процесса (точность, максимальное число итераций и т.д.)

Примеры тестовых данных находятся в директории `data/`.
